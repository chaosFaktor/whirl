A minimal and chaotic actor framework in rust
---------------------------------------------
You should **not** use this. 
The reason I wrote this is that I am fascinated with actor models and wanted to write my own for use in my webserver.

If you are looking for a lightweight actor framework in rust as a actix alternative, consider giving [coerce](https://github.com/LeonHartley/Coerce-rs) or [kameo](https://docs.rs/kameo/latest/kameo/index.html) a look.
